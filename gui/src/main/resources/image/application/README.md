# Bundled application icons

These 64 px PNG files are offline fallbacks. The GUI first asks the operating
system for the icon installed on the user's machine.

- Chrome, Edge, Safari, VS Code, IntelliJ IDEA and Postman are derived from
  Simple Icons releases 16.21.0 and 7.21.0.
- Firefox is derived from Font Awesome Free 6.7.2 because the current Simple
  Icons SVG cannot be rendered by the project's build tooling.
- The curl fallback is a text mark generated locally because neither source
  supplied a compatible rasterizable asset.
